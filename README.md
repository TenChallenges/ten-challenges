This project is for a Lean4 competition. Details can be found at:

[https://github.com/TenChallenges/ten-challenges](https://github.com/TenChallenges/ten-challenges)

Each `Challenges/challenge_NN.lean` contains the canonical `statement_NN`,
the challenge parameter (and any additional data), and the theorem to prove.
Supporting definitions and lemmas live in subject-named modules under
`Defs_and_Lems/`; importing a challenge also makes its supporting definitions
available. Keep docstrings brief and mathematical.
